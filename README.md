# school.logge.top

A static German learning collection with a subject overview, imported teaching units, and a new visual physics chapter about coils and electromagnets.

## Run locally

```sh
python3 -m http.server 8768 --directory site
```

Production serves `site/` directly with nginx. No application server, database, login, runtime build, or API is required. All physics interaction runs locally in the browser. Three.js 0.180.0 is vendored with its MIT license. The 2D explanation and native disclosure solutions remain available without WebGL or JavaScript. Existing imported lessons retain their original browser interactions and font references.

## Content

- Physics: coils and electromagnets, rotatable animated 3D model, cross-section, iron core, Ohm's law, field ratios, electrical power, optional magnetic energy, eight checked exercises and worked solutions.
- Mathematics: quadratic equations and a 90-minute tutoring plan.
- German: picture description for grade 5, including its worksheets and games.
- Pedagogy: movement education.
- Chemistry and technology: the RECTIFY distillation simulation.

The source photo is not published. Its technical values are transcribed as N = 400, I_max = 1 A, R = 3 Ω, L = 3 mH. The field model is schematic. Ratios assume equal length and air core. No absolute field strength or iron-core multiplier is invented. The energy formula assumes constant inductance.

## Visual assets

The homepage has five subject sections with direct links to six teaching units. Its six editorial cover illustrations were generated with the built-in image_gen tool. Original PNGs and optimized WebP versions live in `site/assets/images/`; verbatim prompts and provenance are recorded in `art-source/*prompt*.json`. Covers are illustrative, while interactive field directions remain explicit, deterministic diagrams.

The physics apparatus was modeled in Blender 5.2.1 and exported as `site/assets/models/solenoid-v2.glb`. The editable scene, reproducible generation script, preview render, validation and mesh/animation contract are in `art-source/`. The GLB includes the `InsertCore` animation; the browser uses the same local Three.js version and vendored GLTFLoader. Field markers are schematic and do not represent physical particles. Original learning routes and all eight calculation exercises remain available.

## Maintain

The homepage is generated by `python3 scripts/build-pages.py`; the physics chapter by `python3 scripts/build-physics.py`. CSS and browser JS live in `site/assets/` and are edited directly. Imported units come from the published `public/` tree of LoggeL/static-pages. Their source revision is recorded in `imports.json`. To refresh them:

```sh
python3 scripts/import-lessons.py /absolute/path/to/static-pages
python3 scripts/build-pages.py
python3 scripts/build-physics.py
python3 scripts/check-links.py
```

The import adds a return link and rewrites links to the former GitHub Pages host. The original repository is not modified. The unfinished, untracked Wasserlabor is not included.

Deploy through the GitHub-backed `school` application on the existing Dokploy host. The Dockerfile only copies static files into nginx. Unknown paths return a real 404; deep links resolve to directory indexes.
