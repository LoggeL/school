Modul 3 · Teil 1 · 30 Minuten

Drei Wege zur Lösung. Ein Bild dahinter.

Jede quadratische Gleichung stellt dieselbe Frage: An welchen Stellen trifft eine Parabel die x-Achse? Du lernst drei Wege zur Antwort. Und du lernst, in wenigen Sekunden den passenden auszuwählen.

  • Du erkennst an der Form einer Gleichung, welcher Lösungsweg der schnellste ist.
  • Du löst Gleichungen durch Wurzelziehen und gibst beide Lösungen an.
  • Du löst Gleichungen mit dem Nullprodukt, ohne durch x zu teilen.
  • Du setzt mit Vorzeichen in die Lösungsformel ein und sagst vorher, wie viele Lösungen es gibt.

Die Minuten sind ein Richtwert. Wird es knapp, lass die Aufgaben mit dem Etikett „Knobeln“ zuerst aus und hol sie später nach.

MerkeAlle drei Wege beantworten dieselbe Frage: Wo trifft die Parabel die x-Achse oder eine waagerechte Linie? Darum hat eine quadratische Gleichung immer zwei Lösungen, genau eine Lösung oder keine Lösung. Die Lösungsformel klappt bei jeder Gleichung. Die beiden anderen Wege sind Abkürzungen mit weniger Zeilen und weniger Fehlerquellen.

Minute 4 bis 9 · Entdecken und rechnen

Weg 1: Wurzel ziehen

Kommt x nur im Quadrat vor, löst du die Gleichung nach x² auf. Dann steht da x² = c. Im Bild heißt das: Wo trifft die Normalparabel y = x² die waagerechte Linie y = c?

BeobachteStell c nacheinander auf 9, 4, 1, 0 und −2. Zähle jedes Mal die Schnittpunkte. Warum gibt es zu jedem Punkt rechts einen zweiten Punkt links?

Rechenweg Schritt für Schritt

  1. 2x² − 18 = 0| + 18

    Es gibt kein einzelnes x. Also löst du nach x² auf. Zuerst kommt die Zahl nach rechts.

  2. 2x² = 18| : 2

    Der Faktor vor x² muss weg.

  3. x² = 9| √

    Jetzt steht x² allein. Im Bild liegt die Linie auf der Höhe 9.

  4. x = 3  oder  x = −3

    Zwei Zahlen ergeben quadriert 9, denn 3 · 3 = 9 und (−3) · (−3) = 9. Im Bild sind das die beiden Schnittpunkte.

  5. L = {−3; 3}

    Probe mit x = −3: 2 · (−3)² − 18 = 2 · 9 − 18 = 0. Mit x = 3 kommt dasselbe heraus.

MerkeDie Gleichung x² = c hat für c > 0 zwei Lösungen: x = c und x = −c. Für c = 0 gibt es genau eine Lösung, nämlich 0. Für c < 0 gibt es keine Lösung, weil ein Quadrat nie negativ ist.
Typischer Fehler: nur die positive Wurzel
x² = 16, also x = 4
x² = 16, also x = 4 oder x = −4
Auch (−4)² = 16. Im Bild ist das der goldene Punkt links. Wer ihn vergisst, verliert die halbe Lösung.

Auch das ist Wurzelziehen

Klammer im Quadrat

(x − 1)² = 9| √
x − 1 = 3  oder  x − 1 = −3| + 1
x = 4  oder  x = −2
L = {−2; 4}

Nicht ausmultiplizieren. Die Klammer bleibt zusammen, bis die Wurzel gezogen ist. Probe: (4 − 1)² = 9 und (−2 − 1)² = (−3)² = 9.

Diese Form entsteht immer, wenn du eine Scheitelpunktform aus Modul 1 gleich 0 setzt: Aus (x − 1)² − 9 = 0 wird (x − 1)² = 9.

Keine Lösung

x² + 4 = 0| − 4
x² = −4
L = { }

Kein Quadrat ist negativ. Im Bild liegt die Linie y = −4 unter der Parabel und trifft sie nie. Die leere Menge ist hier die richtige Antwort.

Minute 9 bis 15 · Entdecken und rechnen

Weg 2: Der Satz vom Nullprodukt

Ein Produkt ist genau dann null, wenn mindestens ein Faktor null ist. Steht eine Gleichung als „Produkt = 0“ da, zerfällt sie deshalb in zwei ganz einfache Gleichungen. Im Bild sind die beiden Faktoren die beiden Nullstellen der Parabel.

BeobachteZieh die beiden Punkte auf der x-Achse und lies die Faktoren ab. Stell dann mit dem Regler verschiedene x-Werte ein. Bei welchen x wird das Produkt 0? Was passiert, wenn beide Punkte auf derselben Stelle liegen?

Das Produkt steht schon da

(x − 2)(x + 5) = 0
x − 2 = 0  oder  x + 5 = 0
x = 2  oder  x = −5
L = {−5; 2}

Du liest die Lösungen fast ab. Achte nur auf das Vorzeichen: Die Klammer (x + 5) wird für x = −5 zu null.

Erst ausklammern

Fehlt die Zahl ohne x, steckt in jedem Summanden ein x. Dann stellst du das Produkt selbst her.

  1. x² = 4x| − 4x

    Auf beiden Seiten steht x. Bring alles auf eine Seite, damit rechts 0 steht. Teile nicht durch x.

  2. x² − 4x = 0| x ausklammern

    Die Zahl ohne x fehlt. In beiden Summanden steckt ein x.

  3. x · (x − 4) = 0

    Ein Produkt ist null, wenn ein Faktor null ist. Im Bild springen die Nullstellen auf 0 und 4.

  4. x = 0  oder  x − 4 = 0

    Der erste Faktor liefert sofort x = 0. Der zweite liefert x = 4.

  5. L = {0; 4}

    Probe mit x = 4: links 4² = 16, rechts 4 · 4 = 16. Probe mit x = 0: links 0, rechts 0.

MerkeBring die Gleichung auf die Form „Produkt = 0“. Setz dann jeden Faktor einzeln gleich 0. Fehlt die Zahl ohne x, ist x = 0 immer eine der Lösungen.

Der Klassiker: durch x teilen

Typischer Fehler: eine Lösung weggeteilt
x² = 4x  | : x→  x = 4,L = {4}
x² − 4x = 0→  x · (x − 4) = 0,L = {0; 4}
Durch x darfst du nur teilen, wenn x nicht 0 ist. Hier ist x = 0 aber selbst eine Lösung, und genau die geht beim Teilen verloren.

Schalte im Bild zwischen beiden Rechenwegen um. Beim Teilen wird aus der Parabel eine Gerade. Eine Gerade trifft die x-Achse nur einmal.

Minute 15 bis 25 · Entdecken, rechnen, üben

Weg 3: Die Lösungsformel

Kommen x², x und eine Zahl gemeinsam vor, hilft keine Abkürzung mehr. Die Lösungsformel funktioniert immer. Sie verlangt nur eine saubere Vorbereitung: Rechts muss 0 stehen, und du liest alle Zahlen mit Vorzeichen ab.

Welche Formel benutzt deine Klasse? Die Seite zeigt dann überall den passenden Rechenweg.

x₁,₂ = −p2 ± (p2)² − qp-q-Formel für x² + px + q = 0. Vor x² darf keine Zahl stehen.
x₁,₂ = −b ± b² − 4ac2aabc-Formel für ax² + bx + c = 0

Im Bild sagt die Formel etwas Einfaches: Geh zur Mitte der Parabel, also zur x-Koordinate ihres Scheitels. Von dort liegen die beiden Lösungen gleich weit nach links und nach rechts. Wie weit, das verrät die Wurzel.

BeobachteLass p = −6 stehen und verändere nur q. Bei welchem q rücken die beiden Lösungen zu einer zusammen? Welche Zahl steht in diesem Moment unter der Wurzel? Und was passiert, wenn du q noch größer machst?Lass b = −6 stehen und verändere nur c. Bei welchem c rücken die beiden Lösungen zu einer zusammen? Welche Zahl steht in diesem Moment unter der Wurzel? Und was passiert, wenn du c noch größer machst?

    Rechts steht 0, und vor x² steht keine Zahl. Du kannst direkt ablesen.

  2. p = −6q = 5

  5. x₁ = 1x₂ = 5L = {1; 5}

    Probe: 1 − 6 + 5 = 0 und 25 − 30 + 5 = 0.
